## 1. 最终配置（甜点）

| 参数 | 值 | 理由 |
|---|---|---|
| `n_classes` | 4 | 足够多的类才能让"类间反转"有发生空间 |
| `n_features` | 10 | 高维下小样本真实过拟合 |
| `regime` | `hetero` | 类难度异质 |
| `var_lo / var_hi` | 0.2 / 1.3 | **宽**类方差跨度 → 类间绝对 loss 水平差异显著 |
| `n_per_class_member` | 60 | 小样本 → 过拟合 |
| `n_per_class_nonmember` | 150 | 保证参考分布可估（每类 ≥ 2 样本） |
| `attack_train_frac` | 0.5 | 拟合/评分各半，降方差 |
| `target_hidden` | 16 | **小**容量 |
| `target_epochs` | 800 | **适度**过拟合，非完全记忆 |
| `target_lr` | 0.05 | 与 epoch 数匹配 |
| `difficulty_seed` | 7 | 固定难度剖面，与 benchmark seed 解耦 |

## 3. 机制验证：旗舰到底靠什么赢

这是本轮实验最有价值的产出。旗舰的逐类 z 分数在**类内**是 loss 的单调仿射变换，
因此**不能改变类内排序**——增益只能来自**跨类重排**。

### 3.1 失败路径一：训练不足（无过拟合）

低维（d=2）+ 大数据量时，MLP 泛化良好，member/non-member loss 分布几乎重合，
**所有攻击 AUC ≈ 0.5**，任何方法都无信号可言。

### 3.2 失败路径二：完全记忆（过拟合过头）

`hidden=256 / epochs=3000` 下逐类 loss 实测（members）：

```
class 0: 0.008   class 1: 0.011   class 2: 0.023   class 3: 0.015
```

所有 member 都被记忆到 loss ≈ 0，**不存在"难类 member 仍高 loss"的样本**，
于是没有跨类反转可供修正。逐类归一化在此只引入估计噪声：

| 配置 | 全局阈值 | 逐类 z | 朴素 LR | 结论 |
|---|---:|---:|---:|---|
| var[0.5,0.9] hid=256 ep=3000 | 0.700 | 0.694 | 0.680 | 旗舰略**输**全局阈值 |

> **这是本项目最反直觉的结论**：把目标模型训得越狠，旗舰优势越小。

### 3.3 成功路径：适度过拟合 + 宽类方差

`hidden=16 / epochs=800`，类标准差 ∈ [0.2, 1.3]：

| 配置 | 全局阈值 | 逐类 z | 朴素 LR | z − LR | t |
|---|---:|---:|---:|---:|---:|
| var[0.2,1.3] ep=800 hid=16 | — | 0.727 | 0.680 | **+0.047** | **29.01** |
| var[0.2,1.3] ep=400 hid=32 | — | — | — | +0.040 | 5.15 |

机制成立：难类 member 的绝对 loss 高于易类 non-member，全局阈值/LR 因此误排；
逐类归一化把各类拉到同一尺度，纠正这一类反转。

### 3.4 对照：iso 档（各类等难度）

无类间偏差 → 无反转可修 → 旗舰**退化为与全局基线持平**（有测试断言 Δ > −0.02）。
这正好反证了旗舰的增益来源确实是"消除类间偏差"，而非某种玄学炼金。

## 4. 被证伪的假设（诚实记录）

| 假设 | 结论 |
|---|---|
| "多特征（loss+conf+entropy+margin）融合一定更强" | ❌ 攻击训练集小时 LR 过拟合，纯 loss z 最优。实测加特征使 Δ 从 +0.044 掉到更低 |
| "类样本数不均衡（member_counts）能制造难度异质" | ❌ 非成员等比放大后无先验偏移捷径；且该捷径一旦存在，测的是"先验偏移"而非 MIA |
| "训练越久成员信号越强" | ❌ 完全记忆会抹掉跨类反转，旗舰优势归零 |
| "逐类归一化总是优于全局阈值" | ❌ 仅在类间绝对 loss 差异显著时成立 |

## 5. 统计口径说明

逐 seed 的 AUC 标准差（~0.02）**不能**直接用于两组比较——不同 seed 的数据分布本身
在变，两次独立估计的方差包含"数据集差异"这一共同噪声源。正确做法是**配对**：

```
diffs[i] = AUC_flagship(seed_i) − AUC_baseline(seed_i)
t = mean(diffs) / (std(diffs, ddof=1) / sqrt(n))
```

本项目用配对**单侧** t 检验，门槛 t ≥ 1.833（df=4, α=0.05）。
